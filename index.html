Tandem Malfunction Bitmask Parser

Decode a Tandem t:slim X2 / Mobi status bitmask into the subsystems / notifications it represents. Each set bit maps to one entry, exactly like pumpx2's MalfunctionBitmaskStatusResponse and the alert/alarm/CGM/reminder status responses.
